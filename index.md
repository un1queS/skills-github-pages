## 🛠️ Технологии

- Python 3.8+
- Flask - Веб-фреймворк
- Flask-SQLAlchemy - ORM для работы с базой данных
- Flask-Login - Управление сессиями пользователей
- SQLite - База данных (можно переключить на PostgreSQL/MySQL)
- Werkzeug - Утилиты для работы с файлами и безопасностью
- Jinja2 - Шаблонизатор
